# スマイルスタディ 講師研修テスト

新人講師向けの研修確認テストです。研修資料（Miro「越谷校 研修」）と研修動画（第1〜3回）の内容から出題し、満点がとれるまで何度でも挑戦できます。

- 問題数：44問（研修資料から30問・研修動画から14問。出題順と選択肢の並びは毎回変わる）
- 制限時間：10分（時間切れになるとその時点の回答で採点）
- 1問ずつ表示し、答えると自動で次の問題へ進む
- 結果：点数、5分野の5段階評価（五角形グラフ）、まちがえた問題の正解・解説・スライド画像
- ヘッダーのロゴを押すとスタート画面に戻る
- 満点になるまで「もう一度挑戦する」ボタンが出続ける
- 点数やデータは保存しない（その場限り）

## 使い方

ビルド不要の静的サイトです。JavaScript のモジュール機能を使っているため、`index.html` をダブルクリックで開くのではなく、Webサーバー経由で開きます。

```sh
npm start          # http://localhost:3000 で開く
```

GitHub Pages など、静的ファイルを置けるサービスならそのまま公開できます。

## よくある変更

| やりたいこと | 直す場所 |
| --- | --- |
| 問題を追加・修正する | `js/data/questions.js` |
| 制限時間・問題数を変える | `js/config.js` |
| 解説のスライド画像を足す | `assets/slides/` に置いて、問題の `image` に書く |
| 分野の分け方を変える | `js/data/areas.js` |
| スマるんの画像を差し替える | `assets/images/` に置いて `js/config.js` の `images` |
| 色を変える | `css/variables.css` |

変更したら `npm test` を実行して、問題データの形とテストの仕組みが壊れていないか確認します（PRでも自動で実行されます）。
