# 決めたことの記録

## 2026-10-20 最初の方針

- **作り方**：ビルド不要の静的サイト（HTML / CSS / JavaScript を別ファイルに分ける）。ライブラリは使わない。理由：簡易的なテストでよく、あとから誰が見ても読める形にするため。
- **問題データ**：`js/data/questions.js` に JavaScript の配列で持つ。JSON ファイルにしないのは、読み込み処理なしで import でき、コメントで出典を書けるため。
- **出題**：全50問（研修資料30問＋研修動画20問）を毎回すべて出し、順番と選択肢の並びをシャッフルする。答えの位置ではなく内容を覚えないと満点がとれないようにするため。問題を増やした場合は `config.js` の `questionCount` 問をランダムに選ぶ。
- **資料と動画で数字が違うところ**：指導報告書の文字数は、越谷校の資料（300字以上）に合わせた。動画の「170字以上が目安」は出題しない。
- **キャラクター**：スマるんの画像は研修動画の画面から切り出して使う。
- **結果の出し方**：点数と各問の ○ × だけ。正解は表示しない（資料・動画で見直してもらうため）。
- **満点まで終わらない**：満点でないときは「もう一度挑戦する」を出し、満点のときだけ消す。
- **データ保存**：しない。リロードすると最初からになる。
- **自動テスト**：Node.js 標準のテスト機能（`npm test`）で、採点の仕組みと問題データの形をチェックする。PR ごとに GitHub Actions で実行する。
- **開発の進め方**：`main` に直接 push しない。ブランチを作ってプルリクエストで変更する。
